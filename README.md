# Dragon Quest III — Guide de collecte

Ouvrez [`index.html`](index.html) dans un navigateur pour utiliser une checklist autonome de **Dragon Quest III HD-2D Remake**.

Elle classe les actions par chapitre et distingue l’histoire, les objets importants, les mini-médailles et les quêtes annexes. Chaque relevé contient un lieu et un repère de recherche ; les coches et les compteurs sont enregistrés localement dans le navigateur. Un lien vers la solution SuperSoluce permet d’ouvrir les cartes et captures autorisées correspondant aux zones.
